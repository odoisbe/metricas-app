O que o app acessa

Com a autorização do dono da conta, o app lê, em modo somente leitura, as estatísticas dos canais do YouTube desse mesmo dono: visualizações, tempo de exibição, retenção, origem do tráfego, dados demográficos agregados, impressões e taxa de cliques. Os escopos usados são yt-analytics.readonly e youtube.readonly.

Como os dados são usados

Os dados servem apenas para gerar relatórios de desempenho dos próprios canais. Eles não são vendidos, compartilhados com terceiros nem usados para publicidade.

Onde os dados ficam

Os relatórios e o token de acesso são guardados apenas no computador do dono do app. Não há servidor nem banco de dados externo.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Basta apagar os arquivos locais para remover os dados já baixados.

Uso das APIs do Google

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Contato

Pelo e-mail de suporte exibido na tela de autorização do Google.
